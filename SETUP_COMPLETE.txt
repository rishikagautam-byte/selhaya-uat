🔄 HOW IT WORKS

User Journey:
  1. User clicks product in collection
  2. Resilience component patches URL automatically
  3. Navigate to: /products/{handle}/{shopify-gid}
  4. Products component loads product page
  5. User sees product details

Data Flow:
  App startup
    ↓
  preloadProductURLs() - Cache all from Shopify
    ↓
  Component renders
    ↓
  createPatchedDataWithShopifyURLs() - Convert URLs
    ↓
  Display with patched URLs
    ↓
  User clicks → Navigate with Shopify URL

❓ TROUBLESHOOTING

Q: URLs not changing on click?
A: Hard refresh (Ctrl+Shift+R) and check console for errors

Q: Shopify IDs not fetching?
A: Check .env has correct credentials, verify GraphQL errors in Network tab

Q: Old URLs not working?
A: Fallback route exists at /product/:productName, check console for errors

Q: Build error about imports?
A: Clear node_modules & rebuild:
   rm -rf node_modules
   npm install
   npm run build
